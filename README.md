# ETH/USD Price Action Strategy 📈

## Overview
Real-time Ethereum (ETH/USD) technical analysis using Smart Money Concepts (SMC) and Price Action strategy.

## Strategy Components
- **Swing High/Low** — Key market structure points
- **BOS (Break of Structure)** — Trend continuation signals
- **CHoCH (Change of Character)** — Trend reversal signals
- **Liquidity Zones** — Buy-side and sell-side liquidity levels

## Data
- Source: Yahoo Finance (yfinance)
- Timeframe: 1 Hour candles
- Period: Real-time 7 days

## Tools
- Python, Pandas, Matplotlib, yfinance

## Key Findings
- Bullish BOS signals trend continuation upward
- Bearish CHoCH signals potential trend reversal
- Liquidity zones mark areas where price likely revisits
